Chào bạn, mình là Ngô Đại Hải

Mình hiện là sinh viên Công nghệ thông tin tại Học viện Công nghệ Bưu chính Viễn thông (PTIT). Mình có niềm đam mê lớn với lập trình Python, đặc biệt là Computer Vision, và đang định hướng phát triển sự nghiệp trở thành một Kỹ sư AI.

Kỹ năng của mình

Python

Phát triển Desktop App (Pygame), xử lý Computer Vision.

Web Development

Thành thạo HTML, CSS, JavaScript cơ bản.

Cơ sở dữ liệu

Thiết kế ERD, tối ưu hóa truy vấn SQL.

Công cụ

Quản lý mã nguồn với Git & GitHub.

Dự án tiêu biểu

Messi Interactive Web

Trang web tương tác vinh danh sự nghiệp của Lionel Messi, sử dụng HTML/CSS/JS thuần để tạo hiệu ứng mượt mà.

Database Quản lý siêu thị

Thiết kế lược đồ quan hệ ER và viết các kịch bản truy vấn SQL phức tạp để quản lý hệ thống bán hàng.

Countdown Timer App

Ứng dụng đếm ngược thời gian với giao diện đồ họa, lập trình bằng Pygame và đóng gói (.exe) bằng PyInstaller.
